# GOREN landing — redesign implementation record (2026-09-09)

Implementation of `handoffs/furniture/FABLE-IMPLEMENTATION-PROMPT.md` (internal direction name: "the
everyday monument"). Preview only: nothing was deployed, and no real lead, WhatsApp message or
e-mail was sent at any point.

## How to run

```
npm run build          # python build.py -> dist/ (preview build; prints the readiness report)
npm run dev            # build + local preview at http://127.0.0.1:4173 (lead POSTs answer 503 preview_only)
npm run test:local     # build + the isolated Playwright suite (every API write intercepted)
python -m unittest tests.test_handler -v     # backend unit tests, no AWS, no network
python build.py --production                 # refuses to build and removes dist/ while blockers remain
node tools/shots.js renders-test/shots --full   # QA screenshots: both locales, nine viewports
python tools/subset_numerals.py              # re-cut the shared numerals/punctuation font subsets
python tools/product_assets.py               # re-encode the product renders and the manifest
```

Never run `tests/smoke.spec.js` / `playwright.config.js` as part of design work: that suite targets
production and creates real test leads.

## What changed and why

| Area | Change |
|---|---|
| Composition (`site/index.html`) | Compact masthead → identity + headline → uninterrupted studio portrait (2.2:1 desktop, dedicated 3:2 mobile) → price / preorder context / callback band → one table two states (locked-camera comparison, three labelled finish crops) → one home scene → two material details plus a labelled edge section → dimensions (drawings, data rows, estimator behind a disclosure) → offer rows and three steps → FAQ → form with a summary beside it → seller footer. Gone: the 60/40 room-image split, the gallery carousel, the packaging drawing, the "why this price" cards, the duplicated spec sheet, the giant sign-off, the public 3D viewer, the rolling delivery-date calendar. |
| Tokens (`styles-next.css`) | The brief's palette exactly (#F4F1EA paper, #E7E3DA mineral band, #252720 ink, #62645C secondary, #D1CEC5 rule, #77796F border, #493339 action / #36252A hover, #A52C2C error). IBM Plex Sans Hebrew 400/600; hero 36→60 px, h2 28→42, body 16.5/18, price 30/36; zero tracking; logical properties only; thin rules instead of cards; one restrained entrance (12 px, 360 ms, once) on the home and detail figures; reduced motion respected. |
| Behaviour (`app-next.js`) | Asset URLs come from `window.FX.assets` (manifest-driven and content-hashed, never assembled by convention). Decode-before-swap crossfade for the comparison picture, with an AVIF→WebP retry and the old image retained on failure. Phone rule mirrors the server exactly. Duplicate-submission guard. The honeypot's success answer no longer counts as a conversion. WhatsApp click emits first-party `whatsapp_click` plus Meta `Contact` only; `Lead` fires only on a saved enquiry. The estimator reports numbers, announces once per value, and states what it does not account for. The sticky bar hides over the form and while any field is focused. Section views count at 35 % or half a viewport. Attribution is stored as one timestamped record, so a campaign is never assembled from the leftovers of several visits. |
| Copy (`i18n/*.json`) | Rewritten around the brief's draft lines. Unsupported claims removed (see `assets-src/product/REGISTER.md`). Every image labelled a render or a visualisation. Consent split into a short label plus a readable disclosure, meaning preserved; `CONSENT_VERSION` bumped to v2 because the wording changed. he/en key parity is enforced by the build. |
| Build (`build.py`) | Dimensions read from `content.json` — one source for copy, drawings and JS. Product manifests merged. Art-directed `<picture>` and exactly one preload per hero variant, with the breakpoint written as a range so the two halves partition exactly. Publication inventory follows references outward from the reachable documents, so an unpublished legacy sheet cannot keep its dependencies alive. Content-hashed asset filenames with rewritten references. Readiness report; `--production` refuses and removes `dist/`. |
| Assets (`site/assets/product/`) | 18 manifest entries: studio hero (desktop + mobile), six comparison renders from one locked camera, edge and frame details in three finishes, finish crops, social card, plus the AI-assisted home scene (3:2 and a dedicated 4:5 mobile crop). Provenance, camera data and rejections in the manifests, `RENDER-LOG.md` and `HOME-SCENE-LOG.md`. Everything is provisional (procedural geometry, no manufacturer reference) and labelled as such on the page. |
| Fonts | The Hebrew page was pulling both 19 KB Latin faces for its digits, its punctuation and — all along — the plain space, which no Hebrew subset covers. `tools/subset_numerals.py` cuts a ~5 KB numerals-and-punctuation face per weight and `fonts.css` declares it last, so the Hebrew page now loads 39 KB of fonts instead of 58. |
| Backend (`api/handler.py`) | One canonical phone rule (0-, 972-, 00972-, +972-0 variants), documented and mirrored in JS. `lang` and `size` validated and stored; `attributed_at` stored beside the UTM set. Notifications carry size, language, page and the marketing flag. `scripts/daily_report.py` gained `lang` and now defines price exposure the same way the admin funnel does. Endpoint shapes unchanged. |
| Deploy (`scripts/deploy.sh`) | Not executed. Now calls `python build.py --production`, excludes build records from the HTML sync, and documents why the existing immutable cache-control is honest (every asset name carries a content hash). |

## Review round

A seven-lens adversarial review (claims honesty, RTL/bidi, accessibility, functional contracts,
build pipeline, performance, responsive layout) produced 30 findings; each was verified against the
real files before acting. Fixed in this round: the terms pages claiming delivery coverage the page
and the register decline to claim; the English accessibility statement describing a 3D viewer that
does not ship; the privacy retention text contradicting the actual data lifecycle; a missing skip
link on 404; Hebrew placeholder markers inside English sentences; the Hebrew brand in English page
titles; a duplicate `logoTitle` id; the footer landmark labelled "Privacy policy"; hint and error
text polluting input accessible names; an invisible focus ring on the checked segmented option and
an indistinguishable one on the checked finish tile; live regions that were `display:none` while
empty; a no-JS form that submitted personal data as a GET query string; the check mark leaking into
a radio's accessible name; an estimator that announced on every keystroke; `exit` counted twice per
navigation; attribution recombined across visits; `srcset` sizes that did not describe the rendered
width; a preload media gap between 47.99rem and 48rem; an orphan `fonts.css` kept alive by an
unpublished legacy sheet; Windows path separators in the readiness report; and `deploy.sh` never
invoking the readiness gate.

Measured and rejected: `content-visibility: auto` on the six below-fold sections cut Lighthouse
mobile total blocking time from 280 ms to 70 ms, but left those sections blank in full-page
screenshots and drifted the document height by 300–800 px as real heights replaced the intrinsic
estimates. The page is inspected by screenshot and must not lie about itself, so it was reverted;
the note stays in the stylesheet with the numbers.

## QA evidence

- `tests/redesign.spec.js`: **39 tests, passing in Chromium, WebKit and Firefox.** Both locales at
  nine viewports; six finish/state combinations with a pixel measurement proving the open table is
  physically longer in the same frame; persistence; estimator; validation; the phone variants the
  server accepts; a mocked accepted enquiry carrying attribution, size and language; a second click
  while in flight; 422/429/500/offline with the input preserved; honeypot not counted; sticky bar
  including the focused-field rule; WhatsApp absent while unconfigured; reduced motion; dialog focus
  and return; keyboard order; no third-party or 3D payload; metadata and hashed names; secondary
  routes; storage failure.

- Screenshots: `renders-test/shots-final/` (top, full page and eight section shots, both locales,
  nine viewports), `renders-test/shots-secondary/` (thanks, legal, 404, no-JS, 200 % zoom).

  Firefox coverage is Playwright's, not a real Safari.

## Launch blockers (owner decisions, not design work)

See `assets-src/product/REGISTER.md` §3: operator identity and contacts; confirmation of every
product fact; real product photography or validated CAD; the retention rule for enquiry details.
`python build.py --production` refuses to build, and removes `dist/`, until the owner fields are
filled.
