## 4. Продукт (замороженная спецификация — не менять)

- **Тип:** прямоугольный раздвижной обеденный стол, 160 → 220 см, ширина 90 см, высота 75 см. Одна вставка 60 см хранится внутри стола, вытягивается одной рукой.
- **Столешница:** шпон дуба на фанере с массивной дубовой кромкой, толщина 40 мм, снизу скос — визуально тонкий край.
- **Основание:** две А-образные (трапециевидные) рамы из массива дуба, соединённые чёрной стальной балкой под столешницей. Без царг.
- **Сборка у клиента:** 20–25 минут, один шестигранник, 2 коробки (170×100×12 см и 125×40×22 см), ≈0,31 м³, ≈55 кг.
- **Цвета (ровно три):** натуральный дуб, копчёный/тёмный дуб, белёный дуб. Ноги во всех вариантах — тот же цвет, что столешница; балка — чёрная.
- **Покрытие:** масло-воск, матовое, ремонтопригодное.
- **Гарантия:** 5 лет на конструкцию.
- **Цена:** показать ОДНУ цену, с VAT, формат `₪6,490` с пометкой «מחיר השקה» (цена запуска). Если исследование рынка показывает, что для этой спецификации медиана прямых аналогов заметно другая — скорректируй в коридоре 5,490–7,490 и запиши обоснование. Вне коридора — не трогай, пиши в REVIEW.
- **Срок:** «משלוח תוך 8–10 שבועות מאישור ההזמנה» (8–10 недель). Доставка + сборка по всему Израилю — включены в цену. Это pre-launch: статус пишется честно.
- **Что НЕ обещаем:** наличие на складе, шоурум, кастомные размеры, оплату онлайн.

## 5. Фаза 2 — сайт

### 5.1 Структура страницы (сверху вниз)

1. **Hero** — стол, название модели, одна фраза-обещание, цена, две кнопки: WhatsApp (основная) и «השאירו פרטים» (якорь на форму).
2. **Три главных аргумента** (короткие блоки): выглядит как за 10–12k, стоит 6,490 ; массив + шпон дуба, масло, а не лак; 160→220 за 10 секунд — на шаббат приходят все.
3. **Размеры и раздвижение** — интерактивная схема: переключатель 160/220, схема сверху с людьми (6 → 8–10 мест), «влезет ли в мою столовую»: пользователь вводит длину комнаты, видит ответ. Это событие для аналитики.
4. **Материалы** — крупные планы дерева (см. §5.4 про изображения), три цвета как переключатель, меняющий hero-изображение. Каждый выбор = событие.
5. **Как это сделано** — честный блок про фабрику «Импульс», Черновцы: с какого года, что умеет, почему стол разборный (спроектирован для экспорта, а не для склада). Без пафоса.
6. **Доставка, сборка, гарантия** — три карточки. Сборка нашим монтажником.
7. **FAQ** — 8–10 вопросов, которые реально задают: сколько человек, тяжёлый ли, что с царапинами, можно ли другой размер (нет), когда, как платить (после звонка, депозит, остаток при доставке — как план), возврат.
8. **Форма заявки** — имя, телефон, город, выбранный цвет (предзаполняется из переключателя), свободный комментарий, чекбокс согласия на связь + ссылка на политику. Кнопка: «אני רוצה שיחזרו אליי». После отправки — экран «спасибо» + повторная кнопка WhatsApp.
9. **Липкая мобильная панель** — цена + WhatsApp-кнопка, появляется после прокрутки hero.
10. **Футер** — политика приватности, условия, заявление о доступности, контакт, «Pre-launch: הזמנה מוקדמת, ייצור לפי הזמנה».

Отдельные страницы (простые): `/privacy`, `/terms`, `/accessibility`, `/thanks`.

### 5.2 Требования

- Иврит, `dir="rtl"`, `lang="he"`. Полный RTL, включая иконки, стрелки, формы, галереи.
- Mobile-first: 80%+ трафика из Meta будет с телефона. Проверять на 360×800 и 390×844.
- Скорость: Lighthouse Performance ≥ 90 на мобиле, LCP < 2,5 с. Изображения WebP/AVIF, lazy, размеры заданы.
- Доступность: Lighthouse Accessibility ≥ 95; контраст AA; клавиатурная навигация; фокус видим; alt на всём; форма с label и ошибками, читаемыми скринридером; кнопка увеличения шрифта/контраста не обязательна, но заявление о доступности обязательно с моим контактом для обращений.
- SEO минимум: title/description на иврите, OG-теги с hero-картинкой (для превью в WhatsApp это важно), `noindex` НЕ ставить.
- Без cookie-баннера в стиле GDPR-хаоса: короткая полоска о cookies/аналитике с ссылкой на политику — достаточно; Meta Pixel грузить только после согласия/закрытия полоски (решение записать).
- Дизайн: спокойный, много воздуха, дерево на нейтральном фоне, один акцентный цвет. Не «Wolt-ярко» и не «сайт-визитка 2012». Ориентир — DTC-мебель из `landing-best.md`. Никаких стоковых фото людей.
- WhatsApp: `https://wa.me/<WHATSAPP_NUMBER>?text=<предзаполненное сообщение на иврите: «היי, מתעניין/ת בשולחן <модель>, צבע <цвет>»>`. Номер и все ключи — только через env: `WHATSAPP_NUMBER`, `META_PIXEL_ID`, `CLARITY_ID`, `LEAD_NOTIFY_EMAIL`, `ADMIN_USER`, `ADMIN_PASS`. Если чего-то нет в env — сайт работает, соответствующий блок отключён, в REVIEW.md пункт «добавь переменную».

### 5.3 Данные

Таблицы (префикс `fx_`):
- `fx_events` — id, session_id, ts, event_name, props(json), page, referrer, utm_source/medium/campaign/content/term, fbclid, device, viewport, lang, ip_hash (соль из env, сам IP не хранить), user_agent.
- `fx_leads` — id, ts, name, phone (нормализовать в +972…), city, color, comment, consent(bool), consent_text_version, session_id, utm_*, status (new/called/interested/not_interested/deposit).

Эндпоинты: `POST /api/fx/event` (батчами, `sendBeacon` на уходе), `POST /api/fx/lead` (валидация, rate limit, honeypot, при успехе — письмо на `LEAD_NOTIFY_EMAIL` и запись).
