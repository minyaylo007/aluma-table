# ALUMA — стартовый набор страницы Facebook и Instagram

Пустая страница перед рекламой выглядит как однодневка. Этот набор позволяет оформить её примерно за 15 минут. Всё честно:
никаких отзывов, адресов шоурума, «שנות ניסיון» и счётчиков. Каждая картинка — **визуализация**, и на каждом посте
стоит «הדמיה». Цены на постах предварительные, рядом с ними написано «מחיר משוער, טרם אושר». Цифры, тоны и слоганы
взяты из `catalog/products.json`, тексты подписей на картинках — из `tools/creatives/pagekit.json`.

Лист всего набора — **`preview.jpg`**: обложка с безопасной зоной телефона, круглый аватар, сетка Instagram 3×3,
Highlights и посты 4:5 в порядке публикации. Цифры проверок по каждому файлу — в `report.json`.

Пересобрать набор можно одной командой. Она проверяет, что текст занимает ≤ 20 % кадра, контраст ≥ 4.5:1, на каждом посте есть «הדמיה»,
вес ≤ 500 КБ, аватар помещается в круг, а текст обложки — в центр 1080:

```bash
nice -n 19 node tools/creatives/pagekit.js        # → docs/page-kit/
```

## 3. Кнопки

- **Главная кнопка страницы:** «Shop now / Shop on website» (в иврите интерфейса — «הזמנה» или «לקנייה», это подпись
  самой Meta). Ссылка:

  `https://table.central-aparts.store/catalog/?utm_source=facebook&utm_medium=page&utm_campaign=page_button`

- **WhatsApp — вторая точка контакта.** Кнопка у страницы одна, поэтому WhatsApp подключается отдельно: «Настройки →
  Связанные аккаунты → WhatsApp». Номер `{WHATSAPP}` вписывает владелец, тот же, что в `/admin/settings` (META-TEST §1,
  шаг 3). После этого в «Intro» появляется значок WhatsApp. Если Shop now не нужен, можно сделать главной кнопку «Send
  WhatsApp message», а ссылку на каталог оставить в «אודות».
- **Instagram:** «Редактировать профиль → Кнопки действий / Контакты → WhatsApp» с тем же номером.

## 6. Чек-лист (≈ 15 минут)

1. [ ] Создать страницу Facebook «ALUMA אלומה», категория — раздел 1.
2. [ ] Аватар — `avatar-1080x1080.jpg`.
3. [ ] Обложка — `cover-1640x624.jpg`. Проверить с телефона, что карточка с текстом видна целиком.
4. [ ] «אודות»: короткое, длинное, сайт — раздел 2. Адрес и часы не заполнять.
5. [ ] Кнопка «Shop now» со ссылкой из раздела 3. WhatsApp — номер владельца.
6. [ ] 9 постов по порядку (раздел 4), закрепить пост 9.
7. [ ] Привязать Instagram: «Настройки → Связанные аккаунты → Instagram». Там тот же аватар, bio, ссылка в профиле,
       те же 9 постов (или кросс-постинг из Facebook), закрепить 9, 8, 3.
8. [ ] 3 Highlights — раздел 5.
9. [ ] В Business Manager («Настройки компании → Аккаунты → Страницы») привязать страницу к рекламному кабинету
       **1020089278611713** (шекели). Можно и к новому кабинету в ILS, но тогда во всём тесте используйте только его.
10. [ ] Pixel: в Events Manager создать набор данных «ALUMA» и вставить его ID в `/admin/settings`. Шаги 4–6 и 9 —
        в `docs/META-TEST.md` §1, здесь они не повторяются. Без пикселя тоже можно стартовать — META-TEST §2, «Вариант
        без пикселя».

## 7. Что сознательно не вошло

- В задаче написано «שפון אלון». На сайте материал называется «פורניר אלון», поэтому на картинках тоже «פורניר».
  «שפון» осталось только в хэштеге `#שפוןאלון`: так его ищут в Израиле.
- Нет «עץ אלון מלא» и «מאלון»: читается как массив, а массив — только кромки (тот же запрет, что у креативов).
- Нет недель и сроков, скидок, «осталось N», отзывов, «לקוחות מרוצים», «שנות ניסיון», адреса, счётчиков продаж.
  Это проверяет `tests/test_quality_creatives.py` (класс `PageKitTests`).
