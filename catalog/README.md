# catalog/ — товари тесту ALUMA

`products.json` — масив товарів; єдине джерело назв, сітки, цін, тонувань і картинок для вітрини
(`build.py` читає файл, сам файл веде сесія моделей). Схема й правила чесності — `tests/test_catalog.py`
(швидкий набір).

## Поля товару
`id`, `slug` (латиниця), `name`/`tagline`/`description`/`material` — `{he, en}`; `category`
(`dining_table` | `coffee_table` | `media_unit` | `console`); `price_from_ils` = найменша `price_ils` сітки;
`preliminary: true` — ціна й строк не підтверджені фабрикою, вітрина пише «מחיר משוער»; `sizes[]`
`{label, length_cm, width_cm, height_cm, extended_cm?, price_ils}`; `seats` (лише столи) — `{closed, extended}`
як `[від, до]`; `finishes[]` `{id, name, hex}`; `bases[]` `{id, name}` (порожньо — опор немає, як у підвісної
тумби); `lead_time_weeks` `[10, 12]`; `images[]` — див. нижче; `model3d` — `assets/products/aluma3d.js`: `Aluma3D.mount(el, {product, size, finish, base, state, label,
description})` після кліку «צפייה בתלת־ממד» (three.js тягне сам з cdnjs). Доступність: контейнер у фокусі,
стрілки обертають, текстова альтернатива — `label` + `description`, жодної анімації.
`badges[]` `{id, label}`.

## Картинки (`images[]`) — для вітрини
Пише `tools/render_products.js`, руками не правити (джерела й перезбирання — `docs/ASSETS.md`). Кожен запис:
`src` (WebP від кореня сайту, `/assets/products/...`, рідна ширина майстра ≤ 1600, без збільшення), `srcset`
(WebP) і `srcset_avif` — рядки `"/шлях 800w, /шлях <ширина>w"`, для `hero` і `angle` спереду ще `/шлях 400w` (так їх ставить `build.py` у `<picture>`), `jpg`
(запасний), `width`/`height`, `view` (роль кадру, див. нижче),
`finish`, `base`, `state`, `size`, `alt{he,en}` (за змістом, з «הדמיה» / «visualization»),
`kind: "visualization"`, `source` (`ai` — кадр Figma AI, звірений з моделлю; `render` — рендер нашої моделі).
Ролі (`view`), схему погоджено з вітриною 21.10:
| view | Що | Де |
|---|---|---|
| `hero` | інтер'єр, ~3:2, Figma AI | **завжди `images[0]`**: картка, плитка каталогу, og:image, Meta |
| `texture` | торець і шпон дуба без інтер'єру, Blender 4:3 | ofek, saf — одразу після `hero` |
| `angle` | низький ракурс 4:3, Blender | усі |
| `detail` | крупний план деталі ~4:3, Figma AI | усі |
| `open` | розкладений, `state: "open"`, Blender 16:10 | tavor, sahar |
| `mechanism` | механізм крупно, `state`: `half` (розведено на пів вставки: напрямні й складена вставка) і `closed` | tavor — блок «איך נפתח השולחן» |
| `light` | пара для плавної зміни, `light`: `morning` \| `evening`; одна камера, той самий кадр | tavor |

Галерея картки пропускає `mechanism` і `light` — це окремі блоки вітрини.
`wide` (поки лише sahar) — **окреме поле товару, не в `images`**: широкий атмосферний кадр 16:9 Figma AI (1376×768,
`srcset` 800/1376) для шапки сторінки й обкладинок Meta; формат запису той самий, `view: "wide"`. Тонування — лише свотчі
`assets/products/finishes/<finish>.{avif,webp,jpg}`.
Підпис «הדמיה» має бути видно й на самій сторінці біля картинки, не лише в alt.

`model3d` — `assets/products/aluma3d.js`: `Aluma3D.mount(el, {product, size, finish, base, state, label,
description})` після кліку «צפייה בתלת־ממד» (three.js тягне сам з cdnjs). Доступність: контейнер у фокусі,
стрілки обертають, текстова альтернатива — `label` + `description`, жодної анімації.
`badges[]` `{id, label}`.
